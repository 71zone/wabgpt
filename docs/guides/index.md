# Guides

Task-oriented pages for installing, running and extending wabgpt. For background see [concepts](../concepts/index.md); for exact keys, config and API see [reference](../reference/index.md); for day-two operations see [runbooks](../runbooks/index.md).

- [Getting started](getting-started.md): install, the guided first-run setup, and the four ways to run BrowserOS.
- [Managed Docker browser](managed-browser.md): let the native `wabgpt` run its own BrowserOS Neo container, then find, stop or discard it.
- [Run wabgpt as a server](server.md): `wabgpt serve`, the owner token and private access.
- [Docker Compose stack](docker-compose.md): the bundled single-user server stack, what it exposes, and the human sign-in and pairing steps.
- [Host browser mode](host-browser.md): Docker wabgpt against your own native BrowserOS, and switching Compose modes.
- [Extending wabgpt](extending.md): contracts, adapter rules and a worked example for a new channel, assistant, storage or frontend.
